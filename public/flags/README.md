# Flag SVGs

Vendored from [flag-icons](https://github.com/lipis/flag-icons) v7 (MIT), `flags/4x3/*.svg`,
keyed by lowercase ISO 3166-1 alpha-2. Self-hosted so `img-src 'self'` holds and no flag ever
loads from a third party. The `flag-icons` devDependency records provenance and is the update
path: `npm i -D flag-icons@latest && cp node_modules/flag-icons/flags/4x3/*.svg public/flags/4x3/`.
