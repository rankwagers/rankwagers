# Experiment ethics

Forbidden experiment patterns:

- Fake urgency / scarcity
- Deceptive CTAs
- Misleading bonus claims
- Cloaked SEO content
- Overriding operator eligibility or UNKNOWN≠AVAILABLE
- Manipulative dark patterns that harm accessibility

Accessibility checklist required before approval: keyboard, screen reader, focus, contrast, reduced motion, semantics, responsive.

Known accessibility regression → cannot approve.
