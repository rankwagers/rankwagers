# Evidence Combo Methodology (public copy)

Evidence Combo Studio builds multi-selection combinations from markets that already passed RankWagers daily qualification lists.

## What the studio does

- Filters supported goal markets with provider-backed odds
- Applies coverage, sample-proxy, and correlation gates
- Matches a user-selected target odds range and risk profile
- Explains why each selection qualified using shared evidence UI language

## What it does not do

- Guarantee returns or “safe” / banker outcomes
- Invent unsupported markets (BTTS, 1X2, Double Chance, Draw No Bet)
- Claim AI tip generation
- Fabricate operator availability or offers

## Odds

Odds come from the prepared snapshot at generation time and may change. Users should refresh before placing a bet.

## Responsible use

18+ (or legal age). Terms apply. See `/[locale]/responsible-gambling`.
